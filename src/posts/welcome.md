# 欢迎来到我的博客！

这是我使用 React + TypeScript + Vite 搭建的个人博客。在这篇文章中，我会介绍一下这个博客的特点和搭建过程。

## 为什么选择自己搭建博客？

1. **完全可控** - 代码、样式、功能都由自己掌控
2. **学习成长** - 在搭建过程中学习新技术
3. **个性化** - 可以根据自己的喜好定制一切
4. **轻量快速** - 静态站点，加载速度飞快

## 技术栈

这个博客使用了以下技术：

- **React 19** - UI 框架
- **TypeScript** - 类型安全
- **Vite 7** - 构建工具
- **Tailwind CSS** - 样式框架
- **React Router** - 路由管理
- **React Markdown** - Markdown 渲染
